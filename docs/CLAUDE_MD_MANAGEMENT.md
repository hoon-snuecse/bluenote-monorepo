# CLAUDE.md 파일 관리 가이드

> Claude Code AI를 위한 프로젝트 가이드 문서 관리 체계

## 📋 개요

`CLAUDE.md` 파일은 Claude Code AI가 프로젝트를 이해하고 효과적으로 작업할 수 있도록 하는 핵심 문서입니다. 이 가이드는 CLAUDE.md 파일의 작성, 유지보수, 업데이트 방법을 설명합니다.

## 🎯 CLAUDE.md의 목적

1. **프로젝트 컨텍스트 제공**: AI가 프로젝트 구조와 목적을 빠르게 이해
2. **개발 가이드라인**: 코딩 규칙과 패턴 명시
3. **명령어 참조**: 자주 사용하는 명령어와 워크플로우
4. **아키텍처 설명**: 기술 스택과 설계 결정 사항

## 📁 파일 구조

### 계층적 구조
```
bluenote-monorepo/

├── apps/
```

### 상속 관계

- 중복 내용은 최소화하고 참조 활용
- 앱별 특수성에 집중

### 2. 작성 원칙

#### DO ✅
- **명확하고 간결하게**: AI가 빠르게 이해할 수 있도록
- **실용적인 예제**: 실제 사용 가능한 코드와 명령어
- **최신 상태 유지**: 변경사항 즉시 반영
- **구조화된 정보**: 마크다운 헤딩과 리스트 활용
- **중요도 표시**: 이모지나 강조 표시 활용

#### DON'T ❌
- **중복 내용**: 상위 CLAUDE.md와 중복 피하기
- **오래된 정보**: 더 이상 유효하지 않은 내용
- **과도한 상세**: 코드 자체로 알 수 있는 내용
- **주관적 의견**: 객관적 사실과 가이드라인만

### 3. 업데이트 시점

#### 즉시 업데이트 필요
- 📌 **아키텍처 변경**: 기술 스택, 폴더 구조 변경
- 📌 **API 변경**: 주요 함수나 인터페이스 변경
- 📌 **명령어 변경**: 빌드, 테스트 명령어 변경
- 📌 **중요 패턴 변경**: 코딩 규칙이나 패턴 변경

#### 정기 업데이트
- 🔄 **월간 리뷰**: 전체 내용 검토
- 🔄 **분기별 정리**: 구조 재정비
- 🔄 **릴리즈 전**: 주요 변경사항 반영
